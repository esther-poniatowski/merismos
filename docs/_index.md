# Merismos documentation

Orients a reader toward the contract of the regions of a source, the grammar behind it, and the operations of a consumer.

- [Span kinds](span-kinds.md): lets a consumer rely on the regions returned for a source
- [Syntax files](syntax-files.md): lets a consumer declare the grammar of a dialect without code
- [Using Merismos](guide.md): shows a consumer how to segment, mask, read and extend
- [Architecture decisions](adr/_index.md): records the decisions that later work on Merismos must respect
